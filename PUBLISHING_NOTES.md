# Publishing Notes

This is the public-safe Prepper Disk package staged from Dee's Workbench.
It intentionally excludes downloaded PDFs, generated dashboard data, logs,
symlinked site files, personal handoff material, and private record categories.

Included:

- Static dashboard source under `site/`.
- Indexing/status/sync helper scripts under `bin/`.
- Content-pack and sync-source configuration templates under `config/`.
- Safe Identity Reset Kit runbooks and blank templates under `10_Identity_Reset/`.
- Public source notes and category README files.

Excluded:

- Personal documents and records.
- Downloaded official PDFs/HTML content.
- Generated `site/data` and `site/files` output.
- Logs and local server handoff files.
- Any encrypted vaults or secrets.
