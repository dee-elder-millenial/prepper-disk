# Checksums

> DO NOT PUT PLAINTEXT SECRETS HERE. Checksums can prove file integrity, but this folder must not contain passwords, recovery codes, private keys, seed phrases, personal IDs, or unencrypted sensitive documents.

Use this folder later for hashes of encrypted vault files or printable packets if Dee wants a separate identity-reset checksum set.

The main Prepper Disk refresh process also updates:

- `99_Indexes_and_Checksums/SHA256SUMS`
- `99_Indexes_and_Checksums/file-index.csv`
- `99_Indexes_and_Checksums/prepper-index.json`

Remember that filenames and checksums can reveal metadata. Use neutral encrypted-vault filenames when appropriate.
