# Printable

> DO NOT PUT PLAINTEXT SECRETS HERE. Printable pages must not include passwords, MFA recovery codes, seed phrases, private keys, personal IDs, or sensitive account numbers. Actual secrets belong only inside encrypted vault files or a deliberately prepared sealed recovery envelope.

Use this folder for non-secret printouts:

- Recovery order.
- Emergency contacts without sensitive account numbers.
- Blank trackers.
- Instructions for where encrypted vaults are stored.

Before printing, review every page and remove anything that could help an attacker.
