# Security Policy

This repository is intended to contain only the public-safe Prepper Disk app,
scripts, templates, and non-secret runbooks.

Never commit real secrets or personal records, including passwords, recovery
codes, API keys, tokens, SSH private keys, crypto seed phrases, ID scans,
financial records, medical records, or password-manager exports.

The Identity Reset Kit documents an encrypted-vault pattern. Actual vault files
belong outside the repository and should be encrypted before backup or sync.
